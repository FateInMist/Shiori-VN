# VN 图鉴 · 可交互原型

面向 **VNDB（视觉小说数据库）** 的移动端应用原型。交互骨架参考 [Kazumi](https://github.com/Predidit/Kazumi)，配色改为 **VNDB 默认主题的深蓝**（取自 VNDB 官方 `angel.css`：底 `#051523`、区块 `#0d2741`、边框 `#258`、链接 `#7bd`）。

- 纯 HTML / CSS / 原生 JS，无构建、无依赖
- 数据来自 VNDB Kana API（真实数据）
- 收藏、评分会**真实写入**你的 VNDB 账号（需 Token）
- 支持本地缓存与离线打开

## 打开方式

```bash
node serve.mjs 5188
# http://127.0.0.1:5188
```

也可以直接双击 `index.html`（Service Worker 只有 http 下生效，file:// 下仍可用 localStorage 缓存）。

## 功能

### 浏览
- **首页**：居中搜索框、分类胶囊（高分 / 新作 / 人气 / 恋爱 / 奇幻 / 悬疑 / 科幻 / 日常 / 校园 / 泣系）、**每日台词**（大字号）、三列封面墙 + 下拉续页
- **搜索**：实时搜索 + 组合筛选（排序 / 平台 / 年份 / 时长 / 评分下限 / 标签搜索）
- **发售日历**：按月浏览、按发售日分组
- **作品详情**：大幅居中封面 + 封面下方标题、日/英/中多语言标题、评分与时长胶囊、简介（BBCode 简化、剧透可展开）、信息表、三类标签（可点进标签页）
- **角色**：列表 → **角色详情页**（属性标签、生日/年龄/身高/三围/血型、简介、出演作品）
- **制作**：按职位分组
- **发行**：发行版列表（平台 / 语言 / 介质 / 分级 / 语音 / 无修正 / 开发商与发行商）
- **截图**：双列 + 全屏灯箱
- **相关作品**：续作 / 前作 / FD 等
- **标签页**：标签简介 + 该标签下作品（按评分）

### 收藏（需 Token）
- 连接 VNDB 账号后读取真实收藏，按状态筛选，显示评分与统计
- 详情页「加入收藏」：状态（在玩 / 已完成 / 搁置 / 弃坑 / 想玩）→ 真实 `PATCH /ulist/<id>`
- 已收藏时可「移出收藏」→ `DELETE /ulist/<id>`
- 独立「评分」按钮 → `PATCH /ulist/<id>` 写 vote（10–100）
- 未登录点收藏/评分会提示去登录

### 我的
- 主题：深蓝（默认）/ 浅色 / 跟随系统
- 标题语言：VNDB 默认（罗马字）/ 日语原名 / 英语 / 简体中文 / 繁体中文（详情主标题与列表卡片都生效）
- 成人内容遮罩、图片质量
- 离线缓存大小与清除、清除本地数据、退出登录

## 缓存策略

1. **数据缓存**（localStorage，`vnc:*`）
   - 列表 2 小时、详情/角色/发行 24 小时、标签 7 天、收藏 60 秒
   - 采用 stale-while-revalidate：过期数据先显示，后台静默更新
   - 最多保留 ~70 条，按时间淘汰；配额满时自动清一半
2. **静态资源与封面图**（Service Worker）
   - `assets/*`：缓存优先 + 后台更新
   - `t.vndb.org` 图片：缓存优先，长期保留

所以第二次打开几乎是秒开，断网也能看到上次的内容。

## 说明

- Token 只存在浏览器 localStorage，不上传任何服务器。
- 写操作直接改动你的 VNDB 收藏，请用测试账号或自行确认。
- 成人内容封面默认模糊（可在「我的」关闭）。
- 数据版权归 VNDB 及其贡献者，本项目非官方应用。
